

# Clouignitia - Cloud & DevOps Services Website

A modern, colorful, and professional website for your cloud services and DevOps solutions company, featuring a **green & blue** color scheme with clean illustrations.

---

## 🎨 Design & Branding

- **Color Palette**: Fresh green (growth/innovation) paired with trustworthy blue (reliability/tech)
- **Style**: Colorful & Dynamic with clean illustrations
- **Typography**: Modern, professional fonts with clear hierarchy
- **Responsive**: Fully optimized for mobile, tablet, and desktop

---

## 📄 Pages & Features

### 1. **Homepage**
- **Hero Section**: Clean design with a custom cloud/tech illustration, strong headline, and call-to-action buttons ("Get Started" / "Learn More")
- **Services Overview**: Cards showcasing all four service areas (GCP, AWS, Azure, DevOps) with icons
- **Why Choose Us**: Key differentiators with icons (24/7 Support, Multi-cloud Expertise, Certified Engineers)
- **Cloud Partner Logos**: Display GCP, AWS, Azure partnership badges
- **Testimonials/Trust Section**: Client feedback or trust indicators
- **CTA Banner**: Encouraging visitors to get in touch

### 2. **About Page**
- Company story and mission statement
- Team expertise highlights
- Core values (Innovation, Reliability, Partnership)
- Company timeline or milestones (optional)

### 3. **Services Page**
- **Multi-Cloud Solutions** section covering:
  - Google Cloud Platform (GCP)
  - Amazon Web Services (AWS)
  - Microsoft Azure
- **DevOps Solutions** section covering:
  - CI/CD Pipeline Setup
  - Infrastructure as Code
  - Monitoring & Observability
  - Container Orchestration
- Each service with description, benefits, and "Contact Us" CTA

### 4. **Contact Page**
- **Contact Form** with fields:
  - Name
  - Email
  - Company (optional)
  - Service Interest (dropdown)
  - Message
- **Form validation** with proper error messages
- Company contact information (email, phone placeholder)
- Office location with map placeholder
- Social media links

---

## 🧩 Shared Components

- **Navigation Bar**: Responsive with logo, links, and mobile hamburger menu
- **Footer**: Company info, quick links, social media icons, copyright
- **Smooth Animations**: Subtle fade-in effects and hover interactions

---

## ⚙️ Technical Notes

- No backend needed initially (contact form can use email service integration later)
- Placeholder content for illustrations (can be replaced with custom graphics later)
- Built with React, TypeScript, and Tailwind CSS
- Fully responsive across all devices
